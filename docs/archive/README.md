# Documentation archive

This directory contains superseded/historical project evidence retained for provenance.

- `docs/audits/` contains only audit artifacts still referenced by current canonical project state/roadmap/decisions.
- `docs/archive/audits/` contains historical audits that remain recoverable but are not current operating authority.

Moving an audit here does not erase its evidentiary value. Current implementation, governance and execution must use the active canonical documents first.
